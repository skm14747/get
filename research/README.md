# GoEasyTools.com research package

Research date: 2026-10-24. This package is analysis only. It does not implement the site.

GoEasyTools.com is treated as a proposed new entrant. No Search Console property, backlink index, or ad account was available, and none is assumed.

## How to read the scores

Search volume, keyword difficulty, CPC, and publisher RPM were **not measured**. Those fields are `unknown` or `unscored`. The 100-point priority total is `incomplete` on purpose. The build order is an evidence-backed sequencing decision, not a claim that the first tools have the highest search demand.

## Decision in one paragraph

Launch a focused English utility set first, not a four-language PDF directory. The first ten tools are client-side text, percentage, unit, discount, JSON, encoding, and timestamp utilities. PDF head terms show incumbent brand associations in autocomplete across English, French, Spanish, and Arabic, and a target-size PDF compressor cannot be delivered honestly with upstream pdf-lib. Country tax calculators are the strongest localization lead, but only where a dated official rate source exists, and they are a second wave. Display RPM is unknown. US advertiser spend and one network’s published country preference support testing English in the US, UK, Canada, and Australia before valuing other languages.
